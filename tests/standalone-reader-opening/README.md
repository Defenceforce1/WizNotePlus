# PDF设置文案检查与Markdown打开时序诊断

独立小工程，不链接主App或打开账号／数据库。PDF检查只生成设置Ui及当前简体
翻译目录，在offscreen验证页签、短提示、六个单位、索引与数值。保留全部历史
单位对应关系，不通过删选项改变用户已存单位。

Markdown诊断链接现有匹配Qt／固定引擎，使用临时本地合成笔记、临时profile和
合成QWebChannel，只允许本地资源。控件设置WA_DontShowOnScreen、后台插件式
应用，并核对窗口未expose，不打开前台或真实资料。通过现有公开初始化／阅读
回调观察，不读取、改写或反编译捆绑的压缩编辑器内部实现。

入口参数：`reader-opening /absolute/project/share/files plain|math|bare [gated]`，使用
Cocoa平台及匹配WebEngine helper。报告只含合成文本、回调时序、DOM帧签名、
原文保持和加载次数；不是屏幕逐帧录像或真实用户完整窗口的闪烁次数证明。

诊断采用与正常打开相同的初始化／off调用顺序：原始HTML先可见，Markdown
回调后正文结构形成，数学回调再完成排版。记录不支持“文件被加载两遍”；
渲染中间态被提前展示及多次样式应用是当前证据支持的原因。
用户随后授权修正，产品初次Markdown阅读已增加最终就绪后呈现。`gated`参数
使用同一生产head脚本，对照每个可见帧是否只在ready出现。`controls`场景单独
检查失败、超时、编辑、导航退出和旧token帧回调；超时及帧调度加速只属于该
合成夹具，生产保留30秒上限和真实帧边界。控制只作用于临时屏幕CSS，不改
逐篇授权、保存、用户原文或压缩编辑器，不用reload／固定呈现延时掩盖问题。

第204轮补充`cycle [gated]`：使用公开on／off API连续往返编辑／阅读三次，记录
计算后opacity／正文／可编辑状态，比较源文，并检查编辑后的合成文本往返保留。
原203隐藏规则被初始化快照克隆后，六个切换状态均透明；无呈现控制对照与CSSOM
修正后均可见。新规则仅存在于活跃样式表cssRules，序列化style文本为空，避免
还原HTML重新带回隐藏规则。`controls`补旧临时样式清理、相似用户样式保留和
CSSOM规则不入序列化，合计21项。profile及cache显式放入测试临时根，不再生成
项目外命名用户资料。失败复现日志保留，未读真实笔记或改捆绑编辑器内部实现。

第205轮：原生setup完成后通知`wiz-native-editor-setup-state`，临时呈现控制监听
后在下一帧确认当前ready再显示，替代轮询后再等两帧；25ms轮询及30秒超时保留
作回退，原生ready／failed状态仍是权威结果。通知异常不能使成功setup变失败。
控制共32项，覆盖无及时轮询的通知、失败、异常与迟到setup；模式往返六状态、
编辑内容与CSSOM不入HTML保护保持。三组微小合成样本的setup后显示等待从55／
59／62ms降到24／29／26ms，不代表整个App提速比例，公式本身排版成本未减少。

第206轮补`many`（96个公式）和第五参数“旧版扩展文件绝对路径”，只用于以同一
测试二进制比较修改前后的自有markdownEnvironments.js；其余资源／引擎相同。
诊断经MathJax公开MessageHook记录输入／输出／结束阶段及50ms默认section暂停，
不检查压缩编辑器内部。三组普通／裸环境／96公式的数学阶段时间分别258→65、
265→70、373→263ms（单组合成对照，不作通用基准）。SVG经XML规范化后逐项
一致，含编号／引用目标；processing预算和SVG分批参数不变，执行期间仍收到
事件循环计时器。初次可见帧仍ready；模式往返每次重建引擎均重新应用8ms暂停。
序列化不含临时配置，重复配置不增节点，显式非默认值保留，合计38项控制通过。

第207轮补`rapid`和`bare-many`。前者只在合成依赖入口人为延后真实本地MathJax
加载，连续发出on／off请求后放行，22项核对最后模式、唯一有效回调、原文与可见性；
不以模拟提供者通过代替此原生公开接口联测。后者为64个裸公式及两个引用，旧新
SVG规范化对照66个对象一致。另有`tests/compat/markdown-render-review.cjs`，26项
自有扩展的调度／退出／成功失败超时清理／首匹配保持控制；1800段索引匹配对照
仅为合成吞吐，不称整App提速。初次8项旧实现失败和中途4项原生no-op回调失败
保留，最终修正全部通过。
