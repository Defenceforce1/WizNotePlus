## 不需要迁移

可沿用此前测试目录和已保存 CSS。不改 executable、Bundle Identifier、Qt applicationName／organizationName、资料库路径、设置键、模板识别注释、CSS 类名、控件 ID、笔记格式及数学编号规则。无需重新插入模板，不调用安装的旧版为知笔记。

原 Markdown 编辑习惯、公式引擎和“另存为 PDF”保持不变。PDF 定义／定理引用的上下定位偏移仍保留；不增加数学宏、AI、WebDAV、团队或打印功能。

## 使用与边界

先正常退出正在运行的为知笔记，再用隔离启动脚本。完整包中的“隔离试用.command”使用既定独立目录；工作区的“继续现有测试数据-v14.2.command”接续此前专用测试数据和 CSS。不要直接双击 App 绕过隔离设置。只使用测试账号：本地隔离不能阻止该账号的云端同步。

仍是临时签名、未公证的试用包；其他 App 的真实导入、复杂同步、大规模迁移、旧 Safari 剪藏器登录、完整第三方资产再分发审计和未来 macOS 28 未全面验证。保留旧版和真实资料库，暂不直接替换。
