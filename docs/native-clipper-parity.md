# 原生剪藏复现与验收记录

用户要求尽可能复现原版功能和界面。主要基准为本机 Intel-only Mac 分享剪藏器 1.0.5，不以浏览器版截图假冒 Mac 原版。保留旧可用 App；新 App 使用独立标识、独立配对，遵循系统保护，不借用旧官方身份或账户存储。

## 已完成与差异

| 原版流程／能力 | 新实现状态 |
| --- | --- |
| Safari 分享菜单入口 | 系统识别、启用和实际调起已验证，未改旧入口 |
| 添加到笔记、编辑标题 | 紧凑原生表单；标题编辑实际测试通过 |
| 目的账号／文件夹 | 显示客户端当前账号、可选个人文件夹、记住已选文件夹；合成目的账号实际验证 |
| 保存整页／保存选中 | 两种实际 Safari 输入与原始 Wiz 容器落盘通过；选区未混入整页内容 |
| 网页基础样式、表格、数学内容 | 内联计算样式、受限颜色、HTML 表格、MathML 与上标结构通过本地固定网页验证；复杂站点仍待测 |
| 图片 | 已可读取／嵌入图片随正文保存通过；跨域未嵌入图片保留原图链接或占位并提示，不保证全部网页图片完整 |
| 保存进度与结果 | 原生忙碌指示、保存成功显示目的地、错误保留重试及防重复；逐张图片进度尚无 |
| 原剪藏器独立登录／多账号 | 改为连接已登录客户端，减少重复密码存储；尚未做同等独立云端登录／多账号管理。不得以“保留账号兼容”掩盖此差异 |
| 原界面一致性 | 已依静态操作名称和流程收紧到 460×410；没有启动旧 App 取截图，无精确旧动态布局对照，不宣称像素级复刻 |
| 浏览器版正文／标签／备注／选区遮罩 | 参考项目具备，当前未实现；不混淆为本机 Mac 原版已核实功能 |

## 2026-10-14 实际结果

- 新开发签名宿主／扩展 0.1.1 arm64 编译、严格签名验证、10 项 Swift 输入模型通过。
- Safari 运行了新独立编写的 JavaScript 预处理，分享窗口在扩展沙盒内连接合成客户端，整页与选区保存均成功。
- 整页容器检查：全文标记、表格、MathML、上标、计算颜色、嵌入图片均存在。
- 选区容器检查：选中段落存在；全文标记、表格、公式不存在，符合只保存选区。
- 实测发现并修复上标标签遗漏、Gumbo 原始文本缓冲区生命周期问题，最终 10 项 CTest（含剪藏 30 项）通过，Foundation 到本地原始容器联调通过。
- Safari 曾缓存本项目旧草稿进程／注册，单纯注册新版本不足；只注销本项目早期草稿后，新窗口生效。未重启用户 Safari、未关闭用户原有标签页、未修改旧官方剪藏器。
- 合成配对不写入真实钥匙串；真实配对持久化、真实账号同步与另一台 Mac 安装未验证。

测试服务已关闭，成功合成客户端正常结束、其临时库自动清除。开发候选仍在工作目录，主客户端安装版本仍为 rc9（没有新保存桥接），尚不能把“出现分享菜单”当作真实账号升级已交付。下一步先完善差异与真实配对验证，再把配套客户端及剪藏器完整打包、明确签名与未公证状态。
