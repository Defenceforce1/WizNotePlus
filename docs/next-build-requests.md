# 下次构建要求（2026-10-14，用户明确要求）

## 必须处理

1. 恢复笔记标签页关闭按钮的自动隐藏。用户认为 rc8 常显不如自动隐藏好看，此要求覆盖 rc8 的常显设计。应恢复悬停显示、移开隐藏，同时修正新建、切换、重排、关闭邻近页或鼠标进入子按钮后可见状态不同步的问题。保留锁定页保护和原笔记保存/关闭流程，不把“恢复隐藏”当作回退掉问题修复。
2. 尝试修复断网退出卡住。用户报告断网后退出 App，会反复尝试同步、无法退出。优先检查退出同步停止标志、重试/网络等待、线程收尾及本地笔记保存顺序。退出不应无限等待网络恢复；应取消或停止后台重试，并在有界等待内完成退出。必须先确保本地修改已保存，保存失败要明确提示，不能通过强杀进程、跳过保存或清空用户数据制造“退出成功”。
   最新确认：先保存本地修改，再尝试一次最后同步；成功后退出；网络不通或同步超时则停止重试，确认本地保存后退出，待下次联网再同步。不是一开始就取消所有同步。rc9 网络阶段采用 20 秒总期限（含当前同步），不保证整个程序析构在 20 秒内完成。

## 验证场景

- 多个长标题笔记页：新建、切换、重排、连续关闭、鼠标移入/移出及悬停关闭按钮子控件，观察隐藏/显示状态；关闭对应页正确，锁定保护不变。
- 独立合成测试：联网、无法连接/断网、超时、持续重试、同步进行中退出以及本地有未保存修改时退出。不要切断用户整台电脑网络来试验真实账号，不代理触发正式同步或笔记删除。
- 原先用户提交的约 18 秒 QtWebEngine 析构 hang 报告另行跟踪。它说明卡顿发生在退出网页引擎清理阶段，不能直接证明新报告的“断网同步退出”同源，也不能将其中一项修复当作另一项已解决。
