# 第461轮：本地保存回执与退出同步顺序

第460轮的合成复现显示，实际磁盘写入可以早于 saver 发出保存通知。此前退出路径将写线程空闲视为同步已就绪；网络可能先进入关闭状态，最后一笔虽已保存在本地，却没得到一次快速同步的机会。

- Saver 区分 FIFO／磁盘空闲与退出所需的 GUI 回执全部处理。原来的逐笔通知及读取／传输 fence 保持独立，worker 不等待 GUI。主窗口在成功回执中按实际保存的知识库提交快速同步；便签页仍负责自己的脏状态和标题刷新，关闭或切走原页不会丢掉同步请求。失败通知不会提交快速同步。
- 退出先保存，再等现有同步；有迟到修改时继续确认其本地保存及回执，健康网络才继续处理相应的剩余任务。网络约 3 秒没有开始或没有进度、或用户再次按 ⌘Q，即停止等待网络，不重试，也不跳过本地保存和必要的回执处理。仍有本地失败时取消退出，不创建新的全账号同步。
