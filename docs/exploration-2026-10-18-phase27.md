# 第二十七轮：大图片数学笔记与顶栏布局诊断

2026-10-18。14.4.19 已交付候选、14.4.16 冻结回退和 Applications 中现用 App 保持不变；后续开发标记为 14.4.20，不安装。

## 原编辑器的大图片负载

只扩展隔离内存探针：每篇临时 Markdown 保留原来的 16 个公式，并增加两张程序生成的 2048 × 1536 PNG。图片位于测试自己的临时目录，等待浏览器实际完成解码后才采样。沿用现有编辑器、桥接、MathJax、图片过滤及原文往返，不使用真实笔记或外部图片。

初始夹具使用不符合原编辑器图片规则的相对文件名，图片被现有过滤器清空；另外几次运行还使用了未完成重新链接的旧测试二进制。这些失败保留，不归为产品缺陷。夹具改用完整本地文件 URL，没有放宽产品过滤规则。

修正后的短测八项通过；随后 **120 次临时页开关、92 项检查通过**，始终另保留一个当前笔记，检查原文、公式、已解码图片、对象和子进程清理。关闭批次主进程 footprint 约 202 → 204 MiB，暖机后约 200–211 MiB，十秒后约 152 MiB；最终关闭保留页后约 137 MiB。测试实际使用前轮干净修补引擎并启用 Metal API Validation，未报告资源错误。

这些是固定合成负载的观测，不是全 App 长期无泄漏证明；RSS、footprint 与子进程 RSS 总和不可互换。此测试二进制只含随后线程修补的第一版，不冒称验证了全部第二十八轮源码。
