## 使用范围

- MathJax4.1.3＋mathjax-tex4.1.3，沿用 TeX 风格字体；没有换默认 New Computer Modern。
- 保留裸 equation／align 等既有处理、美元分隔符、定理及数学引用、代码排除。
- 兼容已用公开队列／输入对象接口，保留 PDF 私有副本的 TeX scripts 合约。
- A4 与阅读宽度继续走原生导出 FIFO／恢复流程；不更改设置和二级菜单。
- 对 v4 全宽 SVG 做坐标归一和局部适配，避免仅页宽检查通过却裁掉公式笔画。
- 关闭语义增强／语音／额外菜单和默认 textmacros，colorv2 保留旧颜色命令习惯；
  加载官方 safe 扩展，不关闭系统保护。未增加 Touch ID、VoiceOver 或语法检查。

保留整个独立测试目录，双击其中“启动测试版.command”。启动器核对版本／摘要／
签名并使用旁边的“测试资料”；占用启动端口时退出，不关闭现用 App。不要单独
复制 App 后直接启动。未自动创建测试资料、打开账号或安装；登录后仍可同步云端，
独立目录不是网络沙盒，先用合成笔记，不导入真实笔记。

## 字体对照

同 MathJax4.1.3、同无字体核心包、SVG、900px、关闭语音／语义增强，两个字体
按 ABBA 顺序各跑两个新 profile，每个规模排除预热后各10样本中位数：

| 字体 | 64公式 | 256公式 |
| --- | ---: | ---: |
| New Computer Modern | 56.15ms | 185.90ms |
| TeX | 54.65ms | 181.80ms |

本组 TeX 略快约2%–3%，差距小，不能推断所有公式或整个App都有速度优势。
首次加载样本各两组，受文件缓存／进程启动影响，不据此排名；不宣称统计显著性。
本轮采用 TeX 的主要理由是接近旧版外观，不是追求这几毫秒差距。
