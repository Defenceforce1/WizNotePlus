# v14.4-rc10：自动退出策略与原生 Safari 剪藏候选

主客户端构建号 14.4.10，配套网页剪藏开发候选 0.1.1。当前定位为免费个人使用的未公证候选，不是 App Store／Developer ID 正式发行版，也不承诺另一台 Mac 或尚未验证的未来 macOS 无条件兼容。

## 客户端

- 取消新增的退出前保存／最后同步进度弹窗，自动执行已确认策略；原有 `Cleaning on Quit` 清理窗口、取消动作与顺序保留。
- 本地保存失败仍明确阻止退出。先保存本地，最后同步网络阶段有 20 秒总期限；失败／断网／超时后停止重试，待下次联网同步。20 秒不是整个程序析构时间保证。
- 保留标签页悬停关闭、搜索布局、CSS／数学引用、Markdown 编辑习惯和旧另存为 PDF。
- 新增“工具 → 连接原生网页剪藏器”，显示本次目的账号和两分钟一次性连接码。独立 8849 只暴露配对／目的状态／剪藏保存，旧 8848 不变，不开放数据库对象、任意路径或脚本执行。

## 剪藏器

- 独立 arm64 原生系统分享扩展；原版 Mac 的分享入口、标题／账号／文件夹、整页／选中保存流程作为复现目标。紧凑表单、原生取消／默认保存和忙碌指示。
- 接收 Safari HTML，保留基础计算样式、表格、嵌入图片与 MathML；按白名单清除脚本、事件和本地文件访问，不让主客户端抓取网页任意远程资源。
- 新配对不读旧剪藏器钥匙串／App Group，不另存云端密码。使用已登录新版客户端本地保存原始 Wiz 容器，再由客户端正常同步。
- 明确显示目的地；失败保留可重试输入，稳定请求标识防止网络重试重复建笔记。客户端退出／导入导出忙碌、账号不匹配、加密全库模式时拒绝新写入，不绕过保护。

## 已验证

源码构建、10 项 CTest（剪藏 30 项）、Swift 输入模型 10 项、严格开发签名、Foundation 到合成资料库的原始 Wiz 容器联调通过。实际 Safari 调起扩展，沙盒内整页／选区保存通过；整页基础样式、表格、图片、MathML 上标存在，选区未混入整页内容。主窗口 72 项源码回归通过记录见本轮检查目录，部署包验证另附最终验证记录。

静态资源对照没有启动旧 Intel App 或旧剪藏器，未复制其 nib、脚本、图片。参考代码权利链未完整确认时只借鉴功能及公开协议。发现的套接字生命周期、缺失 HTML 属性、参数名大小写、MathML 标签及输入缓冲区问题已添加检查并修复。

## 尚未验证／尚未复现

- 真实配对的钥匙串持久化、真实账号最终同步／冲突、另一台无开发依赖 Mac 的安装与扩展加载。
- 跨域／懒加载图片、复杂页面排版、SVG／canvas；未完整嵌入的内容会显示原图链接或占位及警告。
- 逐张图片进度、同等独立云端登录／多账号管理、旧动态界面像素级一致性。
- 浏览器版参考中的自动正文识别、标签／备注与页面选区遮罩尚未加入；不声称原版全部能力已经复刻。
- 全部笔记加密模式暂不剪藏，未降低现有加密设置。
- 之前约 18 秒 QtWebEngine 清理 hang、长期断网与磁盘故障仍需真实环境验证。

主程序为临时签名、剪藏器为 Apple Development 签名，均未公证。免费开发签名本机可加载的结果不等于长期或多机通用发行承诺。完整依赖随本机候选包提供；公开二进制发行仍受素材／编辑器／Qt 对应源和许可缺口约束，不能靠“测试版”标记免除。
