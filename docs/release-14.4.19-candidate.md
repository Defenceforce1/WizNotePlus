# 14.4.19 候选版

2026-10-18。Apple Silicon 自用候选，免费 ad-hoc 签名、未公证。保持原版图标、编辑习惯、Markdown／MathJax、CSS、资料格式、账号身份与存储目录。不会自动安装或迁移资料；独立剪藏器不变。

## 本次改进

- 修正原生 PDF 打印层的目标坐标变换，改善定义／定理及公式编号的跳转位置；补全 SVG 公式引用目的地。仍由原页面原生导出，保留自动分页与样式，不改用 TeX、不加独立打印 CSS、不重写 PDF。
- 打印临时链接与保存操作串行隔离，避免暂时属性被保存到笔记；恢复失败时保留保存失败保护，不静默写回或丢弃原文。
- 在固定 Qt Quick Widgets 离屏路径修正最后一张 Metal 纹理的所有权。反复打开／关闭笔记时的可复现增长明显改善；保持硬件加速，不宣称全 App 永不增长。
- 链接对话框按实际文档／页面生命周期工作，避免过时查询作用于已切换或关闭的笔记。
- 延续本地保存优先及退出同步三秒连续无进展截止；三秒不是本地保存或持续有进展传输的总时限。保留原退出清理与取消机制。

## 验证范围

干净候选实际通过完整主程序 665 项、自包含包 516 项、前台窗口与链接生命周期 102 项，以及十次关闭重开专项 81 项。独立 Metal 压力 120 次开页／664 项、原编辑器数学页 40 次／32 项通过；九场景／27 个 PDF 目标、十二个定理定义块顶和九份公式编号定位通过。57 页正常 PDF 与对照逐字节同图；并非把截图变成 PDF。

App 约 257 MiB，保留编辑器、数学字体、媒体／图片、PDF、开发者工具和许可。原图标校验一致，47 个 Mach-O 检查及递归签名通过。以上计数是不同工作负载，不简单相加声称独立功能数量。

## 安装与回退

先备份资料、保存笔记并正常退出。由你自行安装，仅替换系统 Applications 的主 App，不创建个人目录副本；首次不要同时运行指向同一资料目录的新旧版本。名称和资料目录暂不调整。旧 PDF 不会自动修复，需以后重新导出。

14.4.16 冻结回退和此前 14.4.18 候选均保留。程序回退不能撤销已经同步到云端的修改；回退前仍需保存、退出和备份未同步数据。未公证可能触发系统提示，不关闭系统保护或执行全局缓存重置。

## 尚未覆盖

本机验证环境为 macOS 27.0.1／Apple Silicon，不承诺所有或未来 macOS。真实云端冲突、全部附件／加密组合、另一台无开发工具的 Mac 和长期使用仍需日常验证；历史间歇顶栏问题未定位到全部时序根因，本轮重复专项通过不代表永不发生。未将本候选安装到现用位置，也未公开发布二进制。素材／字体及完整对应源码的公开再分发核查继续保留。
