# 14.4.20 候选版

2026-10-18。Apple Silicon 自用候选，免费 ad-hoc 签名、未公证。保持原图标、编辑习惯、资料格式、账号及存储目录。不会自动安装；剪藏器不变。

## 本次改进

- 修正后台任务偶发丢失唤醒、需要后一次操作才能继续的问题。
- 回收被替换、清空及退出放弃的待执行任务，减少其持有资源的残留；不执行取消的任务。
- 修正退出等候后台线程时，完成动作再次提交可能造成的互相等待。
- 保留本地保存优先及同步连续三秒无进展截止，不把三秒当作保存或上传总时限，也不强行中断正在执行的任务。
- 延续 14.4.19 的 PDF 目标坐标及离屏 Metal 所有权修补，不替换编辑器、MathJax 或渲染后端，不增加打印 CSS。

## 验证

本轮完整主程序 17 组／687 项、自包含包 516 项、前台窗口与链接生命周期 102 项通过。新的真实队列测试 22 项及独立内存访问／未定义行为检查通过；旧实现的失败对照保留。原编辑器两张大图片及 16 个公式的固定负载完成 120 次开关／92 项，未观察到持续累积。

App 约 257 MiB，保留编辑、数学、图片／媒体、PDF、开发者工具及许可；原图标、47 个 arm64 组件依赖和递归签名通过。计数是不同测试负载，不作为独立功能数量相加。

## 安装与回退

先备份资料、保存笔记并正常退出，由你自行安装，只替换系统 Applications 中的主 App。不要同时运行指向同一资料目录的两个版本；不创建个人目录副本，不改名或迁移资料。

14.4.16 冻结回退、此前候选均保留。回退程序不能撤销已经同步到云端的修改，未同步的本地笔记仍须单独保存。旧 PDF 不会自动修复，需要重新导出。未公证可能出现系统安全提示，不必关闭全局系统保护。
