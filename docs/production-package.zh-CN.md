# 自用生产包与开发诊断包

日常包使用独立构建目录，显式设置`WIZNOTE_BUILD_COMPAT_TESTS=OFF`，保留正常
功能与默认安全机制。不在装有测试入口的增量开发目录直接打日常包。开发测试
仍可ON并在合成资料上运行；两份构建目录分开，防止为体积而丢掉诊断输入。

打包入口读取实际CMakeCache。OFF可继续，缺配置／未知配置拒绝；ON默认拒绝，
只有显式`WIZNOTE_PACKAGE_DIAGNOSTIC=1`允许开发用诊断包。此允许不安装App，
也不改变程序保护。参数仍按[构建记录](engine-build.md)选择新的输出路径；
不能覆盖已安装App或194／195冻结备份。旧文档中直接打ON构建的命令属于历史
诊断包流程，现在需显式允许，不能据此声称旧镜像已重新构建。

199安全精简仅移除兼容测试对象及新主exe副本的本地／调试符号。未剥离的完整
生产可执行文件、构建与本地校验记录保留；签名前后代码和常量段逐项比较。
依赖、MathJax、字体、PDF、图片／媒体、许可未删除。最终App约251.9MiB是
常规文件逻辑字节之和，不是DMG压缩体积或磁盘分配；相对195约258.4MiB减少
6.45MiB（2.50%）。WebEngine仍占大部，不为更大数字移除正常功能或改编引擎。

本机199候选App已做48个arm64组件／依赖、严格ad-hoc签名、资源一致性、生产
测试入口缺席及非GUI路径检查。资源相同不等于全客户端完整试用通过；没有新
DMG、自动安装、公证、Apple签名配置、真实账户或笔记操作。源码与去敏记录可
同步专用GitHub，原始日志、路径、签名资料与二进制留本机。
