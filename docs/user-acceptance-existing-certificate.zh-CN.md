## 先准备正确版本和备份

旧14.4.25安装包冻结于第171轮，旧签名测试副本为第181轮，都没有183／184修复。
新交付名称为WizNotePlus Trial 189，本轮关联1407／0与独立签名／主代码一致性核对，
没有替你运行账户。它保留现用App和旧包，不自动安装，不要求你自行编译。

先保存并正常退出现用客户端，再双击新包旁边的“启动独立测试版.command”。
程序沿用186的固定独立测试目录，不迁移或重置现有测试资料。原首次使用确认
仍保留，已用过186时可继续原测试账户；启动可能同步云端。现用App目录不变，
本地隔离不等于云端隔离，186／187／188／189不要同时运行。

你只需要安排一段方便操作Mac和iPhone的时间，并说明可使用的测试账户／资料范围。
密码、证书、私钥和备份内容不用发送到聊天。操作真实账户前，先由你完成原版
数据备份、保存并正常退出现用App；不要让新旧App同时写同一资料库。仅用你新建
的无敏感内容测试笔记，不在唯一一份重要原笔记上试转换。

## Mac上的一次集中试用

1. 使用已有兼容证书的账户及你知道的证书密码。先确认原官方客户端能打开一篇
   测试加密笔记；若不能，先停止，不新建、重置或替换证书。
2. 在匹配当前源码的测试版打开该笔记。取消一次密码输入，再重新打开；确认原
   笔记没有改变。输入正确证书密码后应正常显示，登录密码不是证书密码。
3. 两种解锁方式使用同一规则：输入一句无敏感内容，短暂切换应用后返回应继续
   编辑；连续离开超过5分钟再返回才重锁。睡眠／会话锁定仍立即生效，不能把
   隔离通知模型通过当作所有物理系统场景已验收。已登记且当前可用的Touch ID
   应自动请求一次验证；取消不循环弹出，点“使用Touch ID”可重试，也可直接
   输入证书密码。外接显示器／合盖等场景以系统实际能力为准，不可用时直接密码。
   若方便可顺手观察该场景；不因检测到了显示器就断言指纹不可用。授权后刚输入
   的内容仍在，不应被旧正文覆盖。隐藏笔记／切换文档仍有各自的许可边界。
   解锁页只保留密码框、解锁与Touch ID按钮；系统验证面板可取消，输入密码也会
   取消当次指纹请求。需要时才附加证书提示或错误，不额外显示标题和模式切换。
   证书已有的密码提示显示在输入框下方，较浅文字、长内容换行；无提示时不占空行。
4. 正常保存、退出、重开同一笔记，核对最新文字及一张内嵌图片。若使用独立附件，
   再核对附件能打开且字节／内容正常；正文加密不能自动证明独立附件也受加密保护。
5. 若要用Touch ID，在设置中显式登记，密码只在本机输入，系统提示时本人按指纹。
   取消一次系统认证应仍锁定，之后应能用密码打开。删除本机记忆后密码仍可用，
   笔记、证书和备份应保持。没打算用Touch ID可以暂不做此项，并记为未验。

复制不改变原规则：解锁后可以复制，重锁阻止新复制及旧许可迟到提交；已经放入
系统剪贴板的内容是明文，不自动清空／撤回，也不控制剪贴板历史或系统同步。

证书不可用或保存失败时先按提示停止，不反复提交密码／转换；记录提示、发生步骤
和测试版标识。若出现“回退未全部完成”，不要继续编辑或同步该测试笔记，保留
提示中的备份文件和原现场。

普通Markdown保存失败已按用户决定停止排查，移出后续计划，不标记已修复；
保留已有保存保护，不再要求为此补充复现资料或测试。

## 官方iPhone客户端的往返试用

1. Mac正常保存并由你完成同步后，在官方iPhone客户端打开同一测试加密笔记，
   核对最新文字和图片／实际使用的附件。
2. 在iPhone加一句测试文字，保存并同步；回Mac正常同步、重新授权，核对该句。
   若出现同步冲突，先保留两份版本，停止覆盖，不用重要原笔记排查。
3. iPhone的Face ID由官方客户端及其设置决定，不由Mac测试版添加或替代。是否
   正常显示、保存和双向同步需要分别记录，不能用Mac的Touch ID通过替代。

## 只在需要时补做的操作

- **永久解除加密：**只对另一篇可丢弃测试笔记操作。先取消一次确认，确认仍加密；
  再输入证书密码并确认，核对明文正文和完整原加密备份路径。原笔记、证书和
  备份不要删除。只有你同意测试明文同步时，才在该测试笔记上继续同步。
- **实际使用的原生操作：**集中选一次PDF导出文件夹／取消、普通复制粘贴／查找、
  外部编辑返回保存或账户头像更换后重开。仅选你实际要用的项目；头像上传和
  截取真实屏幕会改变账号或接触真实内容，不在后台自动操作。
- **更广场景：**切用户、另一台Mac及长期使用只作为未验范围保留，不为宣称完成
  而强制排进本次试用。历史偶发夹具原因和掉电／并发写入原子性也不声称已解决。
