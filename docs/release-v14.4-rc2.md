# v14.4-rc2：合并顶栏

这次主要调整主窗口顶栏，不改变笔记格式、账号或资料库。

- 将原来的系统标题栏和下方工具栏合成一行，按参考图排列红黄绿按钮、账号、同步、搜索、新建笔记。
- 搜索框高度降为 26 像素，采用较柔和的胶囊圆角、边框与聚焦颜色；宽度仍为 340 像素，标签条件和输入文字保留原有行为。
- 主窗口使用 Qt 6.9 之后的原生扩展标题区接口。不替换 Cocoa 窗口代理，不改写系统事件，也不挪动原生红黄绿按钮。
- 全屏模式跟随系统安全区域留边；其他对话框不合并标题栏。
- 保留原有 Markdown 编辑、数学分类与编号、自定义 CSS、另存为 PDF、导入导出和网络安全修复。
- 随包补入 FramelessHelper 的 MIT 许可，并新增捆绑网页组件与素材核查记录。完整许可证／素材来源审计仍未结束。

本机隔离主窗口测试覆盖按钮、模态窗口恢复、全屏退出、关闭重开，以及单行顶栏的对齐与原生点击命中。测试使用临时合成笔记，不读取正式账号或用户笔记。另运行既有 8 项回归测试。
