# 第六十二轮：实际临时数据库／ZIW 导出核对

2026-10-19。只增加合成检查，产品实现仍为第五十九轮；暂停打包、部署、签新副本及安装。

此前资源测试的档案提取是适配器。本轮在原生笔记传输自测中直接使用实际 `WizDatabase`、实际存储的合成 ZIW 和原提取／复制方法，增加七项：成功提取、原 BOM／转义资源路径、实际 PNG 字节、缺失 ZIW 的早期失败、真实资源目录创建失败、失败后的 HTML 中间结果，以及原 ZIW 字节／笔记数量不变。

隔离边界仍在 QApplication、路径解析器和数据库之前建立：临时资料库、缓存和 TMPDIR，只有虚构账号与合成笔记。没有打开用户资料、登录、同步或读取凭据；也没有把资源事务原型链接进主 App 的测试代码。对照远程旧测试文件，确认仅增加该块及一个工具头引用，原测试外围字节不变。

## 结果

- 实际资料包专项从 75 增为 **82 项，连续五轮通过**；原有笔记／文件夹、附件、标签、样式和合成加密传输检查继续保留。本轮未给主程序加 ASan，不能借用独立原型的 ASan 结果。
- 开发目录重编译后，完整 **20 组／843 项通过，126.56 秒**。离屏图形诊断保留，不冒称新的原生前台／PDF 几何／Metal 压力验收。
- 真正的 ZIW 提取后，资源目录被临时文件阻挡时，实际接口返回失败但已写入 HTML，阻挡文件没有被覆盖；这个“通过”是**已知风险的实际复现**，不是修复。原笔记资料包字节和数量不变。
- 实际数据库接口早期失败保留目标，也不意味着 GUI 有效正文路径一定保留：第五十九轮仍沿用原目标删除策略。有效正文后的提取／复制／写入失败保护依然未集成。

本轮覆盖普通合成笔记的实际数据库／ZIW 接口，不覆盖实际编辑窗口到 JavaScript 再到资源事务的完整链路，也未验证加密笔记的单文件 HTML／Markdown 导出或密码交互。一般并发、崩溃恢复、元数据保真及资源事务整体验收继续单列。
