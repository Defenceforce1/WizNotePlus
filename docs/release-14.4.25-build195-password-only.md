# build195：密码解锁／本机免描述文件续签

移除设置中的Touch ID页面及正常解锁页的指纹按钮、自动验证。保留密码输入框、
解锁按钮和原证书密码提示，空密码不能提交。不会显示常驻签名／指纹提示。
原生生物识别钥匙串后端不再进入构件，旧登记标志不能恢复功能；不自动删除旧
钥匙串记录，不读取旧秘密，不以降低保护的密码存储替代指纹。

保留逐篇密码验证、导航返回复用、连续后台五分钟宽限、睡眠／系统锁屏立即
重锁、异步旧许可失效、未保存DOM与保存缓存／队列。不改证书、原文加密格式、
永久解密确认或官方iPhone协议。忘记证书密码没有恢复后门。

新本机包WizNotePlus-14.4.25-build195-password-only-macOS-arm64.dmg，采用
ad-hoc签名，无主程序受限钥匙串权限或嵌入描述文件，因此不依赖七天个人团队
续签。未公证、非公开发行；不承诺任意机器直接运行，不关闭系统保护。

及默认资料目录规则与现用优化版一致。旧build194当前功能备份和旧安装包保留，
原版WizNotePlus.app及网页剪藏器不动。GitHub仅同步源码与去敏记录。
