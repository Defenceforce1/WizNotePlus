# 数学笔记使用说明

## 14.4.24 开发版：编辑／阅读切换后的 PDF 公式引用

修正原阅读器重建页面后打印监听丢失的问题：从阅读进入编辑再返回阅读，导出的公式编号和引用目标
仍会按受控打印流程生成。不会向原始 Markdown 补写内容，打印后仍恢复原 HTML 和修改状态。
此修复只在开发目录，尚未制作新的安装包；已安装的 14.4.23 不会自动获得，既有 PDF 也不会自动改变。

开发源码另增加标准 `multline`／`multline*` 的打印适配：逐行放入实际可打印宽度，保留短行字号、
原有行间距和首行靠左／中行居中／末行靠右，给编号留出空间。只有确实过宽的行会缩小，
不会为了隐藏的屏幕宽度空白而把整段短公式一起缩小。列表、引用块、多位编号和公式内引用
已用隔离合成 PDF 核对；不会把这些临时打印布局保存回笔记。

这不是完整 LaTeX 排版器。显式 `\shoveleft`／`\shoveright`、未知 SVG 结构及复杂定制宏保守沿用
原输出，仍可能有宽度限制；真正很长的单行建议自行使用 `\\` 分行。普通公式、任意 CSS 和
混合页面的既有整页缩放策略没有重写，不能保证任意笔记的绝对字号或分页完全相同。

## 14.4.23：常用 LaTeX 风格定理环境

以下定理功能已进入 14.4.23 试用候选。14.4.22 不包含这项定理语法，也遗漏了普通新笔记改名为
`.md` 后的裸公式初始化路径；14.4.23 已修正该入口，不以旧安装版本的行为代替验收。

支持 `theorem`、`lemma`、`proposition`、`corollary`、`definition`、`example`、`remark`、`proof`，
以及星号不编号形式。开始和结束命令单独占行；开始行可紧接可选纯文本标题和 `\label`，或把标签
放在正文开头单独一行。环境名大小写敏感。完整示例见 [LaTeX 风格定理示例](../share/files/examples/latex-theorem-environments.md)。

```latex
\begin{proposition}[平方非负]
\label{prop:positive}
对于实数 $x$，有 $x^2\ge 0$。
\end{proposition}

见命题 \ref{prop:positive}。
```

定理、引理、命题、推论共用序列；定义和例各自编号；证明、注记与星号环境不编号。
显式 LaTeX 环境无需先启用 CSS 模板；已有数学 CSS 可继续控制样式。旧引用块只有在原有模板开关
启用时才参与编号；两种写法可混合。重复或未知标签不建立误导性定理跳转。

正文使用普通 Markdown，包括段落、粗体、列表、表格、代码和数学公式。支持嵌套的常用定理／证明，
最大 16 层。代码中的环境命令不执行；不完整或不匹配的环境保留文本。不要求也不支持用 `$$` 包裹
整个定理；`$$` 只用于真正的展示公式。当前保证独立顶层环境，列表／引用块里的定理、复杂标题宏、
章节计数、自定义 `\newtheorem`、任意宏包和完整 TeX 文档编译不在本轮范围。

同一环境片段用于真正的 LaTeX 文档时，需在导言区定义这些环境；Markdown 格式的正文也不自动等价于
LaTeX 正文格式。笔记保存仍保留原始环境命令，不补写美元定界符、不把预览生成块写回编辑源码。

适用于 WizNotePlus — Apple Silicon 试用版，试用构建 v14.3，基础版本 2.12.0。保留原来的 Markdown 编辑方式，不增加数学宏，不编译完整 TeX 文档。

## 先开启样式

在“工具 → 笔记样式（CSS）”中点击“添加模板：数学环境（定理／定义／证明）”，然后点“保存”。保存一次，作用于本机所有 Markdown 阅读预览；不修改笔记原文。新试用目录需要重新设置一次。

“添加模板：引用块”统一美化普通引用块；“添加模板：数学环境（定理／定义／证明）”区分定义、定理、例、证明，并开启数学块编号与引用。两者可以同时保留，分类规则在后面时更容易保持预期效果；建议先只用数学环境模板。重复点击同一个按钮不会重复插入同一套模板。

v14.1 及更早试用版中的“笔记正文 CSS”“插入数学引用块样式”“插入分类数学样式”只是旧显示名称。原来的设置、已保存 CSS、模板标记与编号规则仍可沿用，不需要重新插入或迁移。

模板开头的 `/* WizNotePlus scientific math environments v1 */` 是识别开关，请保留。可以修改下面的颜色、边框、背景、间距；关闭 CSS 或取消未保存的预览，会恢复原来的显示。CSS 只使用可信来源，外部字体、图片链接可能联网。

## 继续写普通 Markdown

```markdown
> **定义（实数）** \label{def:real}
>
> 实数集记为 $\mathbb{R}$。

> **定理（平方非负）** \label{thm:positive}
>
> 对任意实数 $x$，有 $x^2\ge 0$。

见定义 \ref{def:real} 和定理 \ref{thm:positive}。
```

标题单独占引用块第一段；`\label` 放在加粗标题后面。正文引用推荐直接写 `\ref{名称}`，不要包在 `$...$` 中。完整示例见 [数学笔记示例](../share/files/examples/mathematical-notes.md)：复制文件里的原始文本到新建 Markdown 笔记，再进入阅读预览。它不是 `.wiznotes` 导入包，不要从“导入原始笔记包”导入这个示例。

支持：定理、引理、命题、推论、定义、例／例子、注／注记、证明，以及相应英文标题。普通引用块、代码块和原始 Markdown 保存方式不变。

## 编号和引用

- 定理、引理、命题、推论共用每篇笔记的序列；定义与例子各自编号。
- 证明和注记不编号。新建另一篇笔记后，计数重新开始。
- `**定理 7（名称）**` 保留数字 7，随后同组的自动编号从 8 继续。
- `**定理 2.3（名称）**` 原样显示 2.3，但不会自动推算章节编号。
- `\label{thm:positive}` 是固定引用名，不是“手动编号为 positive”。增删前面的数学块后，`\ref` 跟随当前编号。
- 引用名在同一篇笔记中必须唯一，限 1–128 个英文字符、数字或 `_ : . / -`。重复标签会提示且不链接；找不到的引用保留原文。
- 只支持同一篇笔记内的数学块引用，不支持跨笔记引用。数学块标签与公式标签请用不同名称。

公式仍沿用原来的 MathJax 2。行内公式用 `$...$`，展示公式用 `$$...$$`；继续使用 `\mathbb{R}` 等完整命令。复合公式中的引用与 `\eqref` 仍由原公式引擎处理，数学块标签没有注册到它的公式编号表。

## CSS 能改什么

分类模板可调整定理的蓝色、定义的绿色、例子的橙色、证明的间距和结束方块。模板中的变量集中在开头，例如 `--math-blue-border`、`--math-green-background` 和 `--math-environment-padding`。

自定义 CSS 负责外观，程序负责识别普通引用块、计算编号、建立引用。随意改变 CSS 计数器，不等于同时改变程序引用的编号规则。也不执行 Notebooks 的专用指令、格式菜单或其附件中的 JavaScript。

## PDF 与数据安全

继续使用原来的“另存为 PDF”，使用当前笔记页面的 CSS；没有新的打印窗口、独立打印 CSS 或新分页引擎。
当前自用候选已包含先前的定位修正，但纸张宽度与屏幕不同，不能保证任意 CSS、公式和分页逐像素一致。
阅读往返后公式目标缺失的修复见本页 14.4.24 说明；请用包含相应修复的版本重新导出。

`.wiznotes` 是本分支的原始笔记交换包，仅验证本分支导入；不能承诺官方为知或其他 App 直接导入。通用 HTML 导出保留正文、资源和附件，但目标 App 的实际导入、标签保留和脚本／公式处理仍未验证。详见 [导入导出说明](native-note-transfer.md)。

v14.3 可直接双击“WizNotePlus Apple Silicon.app”，默认使用独立目录。此前专用测试副本与 CSS 可完整复制后沿用，不需要重复插入模板；新目录中没有样式才需设置。只使用测试账号，本地隔离不能阻止账号云端同步；不要在未备份真实数据前替换旧版。程序仍是临时签名、未公证的试用版。详见 [独立启动说明](standalone-startup.md)。
