# 14.4.16 — 中文设置入口与标签输入修复

日期：2026-10-15。基于 14.4.15，只修正顶部原生设置入口及搜索筛选中的中文输入，不改变笔记格式、Markdown 编辑、CSS／数学、旧另存为 PDF、同步、退出、名称或资料路径。独立剪藏器继续暂停。

## 修复

- Qt 6 的 `qt_zh_CN.qm` 是翻译依赖索引，原包没有随附它所需的 Qt 基础中文目录。现在部署、精简时保留受支持语言的 `qtbase` 目录，Qt 6 直接加载基础目录，Qt 5 沿用旧路径。保留原语言选择与 PreferencesRole；中文环境下原生应用菜单显示“首选项...”，不强改用户设置窗口语言。
- 放大镜内的个人笔记筛选保留原位置、标签／文件夹／附件条件、更多条件和保存搜索，仅把菜单内嵌输入控件改为可获得键盘焦点的非模态工具浮层。点击外部、失活或窗口变化时收起；组合输入时 Escape 不提前关闭。
- 标签查找的中文预编辑不会提交内容搜索或改变所选标签，提交后按名称过滤；主搜索栏组合输入期间暂停补全，不因确认候选的回车提前搜索。原显式选择和搜索流程不变。

## 本轮发现并修正的候选崩溃

首个未交付的 14.4.16 隔离进程在重设输入框父组件／样式时触发新事件过滤器，访问尚未构造的补全器。已将过滤器安装推迟到初始化完成，并初始化／检查指针、先判断事件类型、析构时撤销全局过滤器。这是新生产代码的初始化缺陷，不只是测试脚本故障，也不是已安装 14.4.15 的日常崩溃。随后源码与最终部署回归通过；初次失败和私人报告仅留本机，不随包或 GitHub 发布。
