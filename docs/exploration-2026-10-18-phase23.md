2026-10-18。继续用户批准的探索，不安装、不改现用 App／资料／编辑器／图标。原有 `printToPdf` 路线不换，未使用 PDF 后处理、坐标常量补偿、打印 CSS 或改变窗口宽度。

## 先建立可运行的未修改基线

前轮完整 arm64 引擎编译完成，增量复查返回 0。Core、Widgets、helper 和资源一起复制到独立基线目录；其他框架依赖仍来自同一份 Qt 6.11.3 SDK，不覆盖它。候选引擎复制到另一目录，避免下一次链接改变正在验证的运行时。

实际生成的公开／私有功能头与现用 SDK 比较：私有特性一致；公开特性仅 WebDriver 开关不同（本次默认开、原包关）。它不用于主 App 或这些探针，原版／补丁两次保持同一配置。未因此开启自动化接口或安装 driver。构建仍保留 SDK 27 超出 Qt 测试 SDK 26 的警告。

七个实际载入框架规范路径在 QApplication／profile 创建前核对。候选加载日志同时确认 WebEngine helper 子进程也使用候选 Core，避免仅凭父进程版本号误认补丁。旧阅读器探针也新增同样的启动前核对，属于诊断改动。

自编译**未修改**引擎的九组页型、27 个目的地／点击矩形结果与原 SDK 完全相同，仍复现七种场景偏移；全部 27 页渲染图逐字节相同。这排除了本轮重编译／构建配置本身让样本变准的解释。

## 只改变原生目的地的绘制变换

之后仅对隔离源码应用固定校验值的 `current-page-destinations.patch`，增量编译成功。分页时让具名目的地使用当前页正文的 property-tree 状态，采用与实际绘制相同的页边距、缩放和分页变换；不重复扣除后续页偏移。非分页分支保留原逻辑。

## 真实旧阅读器、公式和科学 CSS

沿用之前的普通、跨页边界、普通 `eq1` 标签三套合成资料，每套仍输出 5 mm、20 mm 及可见标题诊断变体。未修改原 Markdown 源码、MathJax 2.7.6 或科学 CSS。

- 九份 PDF 的原文、HTML、修改状态不变，均无公式报错或远程请求。
- 打印准备／恢复各三次，完成后没有残留临时 SVG2 属性或等待队列；继续使用前轮保存／打印串行候选。
- 每份四个内部链接均精确解析到四个 PDF 目的地，包含有冒号与普通名称的公式标签。公式链接**存在**不等于另行证明其位置精度，本轮不混淆两者。
- 原 block-ID 输出的十二个定理／定义目标均在正确页，纵向准确落在实际彩色块顶部，最大差约 0.000107 pt。标题诊断变体有意把 ID 移入块内，不错误地拿它与外框顶部比较。
- 全部 **30 页**与旧引擎原语料逐字节同图，分页、字体、公式、背景框不变；另实际查看普通及跨页样本。
