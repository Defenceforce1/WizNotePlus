# v14.4-rc7：收起手动头像刷新与紧凑搜索框

用户在 rc6 试用后报告头像测试通过。本版按要求移除账号菜单“刷新头像”，同时移除仅供该菜单使用的等待状态与失败弹窗逻辑；保留启动、成功的手动同步、上传成功后的自动刷新及失败悬浮提示。上传地址、GUID 下载地址、安全校验与原子缓存保留 rc6 修复。

用户报告是实际试用反馈，不等于代理独立认证了真实账号请求。代理回归仍采用临时资料目录、虚构图片与 HTTPS 服务，不触碰真实账号。未知 self-test/probe 拒绝普通启动的保护保留；所有窗口检查使用确切的 `--mac-window-controls-self-test` 参数。

搜索框从 300×26 收紧为 260×24 逻辑像素，圆角随高度调整至 12；底色透明、位置与新建笔记的顺序不改。标签折叠、输入区、放大镜、清除按钮和与笔记列表的对齐逻辑保留，回归检查覆盖较窄尺寸下的标签和输入光标。

不修改笔记数据库、Markdown 编辑习惯、CSS、数学样式、原另存为 PDF、顶栏高度与红黄绿。仍为临时签名的候选版。

接下来优先正式版收尾：完整依赖/素材许可与对应源码核查、可重复构建与恢复说明、长期同步和附件/冲突回归。Developer ID 签名与 Apple 公证需要本地有效证书及私钥、用户自行配置的公证凭据；当前无有效身份，不能冒充已正式签名/公证发行版。暂不新增 AI、WebDAV、团队、宏、完整 TeX 编译或另一套打印流程。
