# 第三十六轮：数学块重复渲染的对象保留核查

2026-10-18，14.4.21 开发源码。仅增加隔离诊断，不改产品实现；继续暂停安装包、部署、签新副本和安装。

## 范围与比较防护

第三十二轮的查找表只在单次装饰调用内存在。本轮检查反复装饰／序列化是否持续积累 DOM 或 JavaScript 对象，而不是据一次速度测量推断内存正常。

新增探针仅在自己启动的隔离浏览器目标中创建临时 iframe。使用实际 editorHelper.js，精确反向还原查找表前的源码，并要求旧版本 SHA256 为 `3ff659b6adfc65332e53e3da3f39e2c87f76deda3437a12258121aee0b91aac0`；当前源码为 `ea620372dd4a22d0aa1afa17b7d4fd200d945e44976ebeefa426b97737c9d9b7`。缺少基线、错误基线、拿同一份旧源码自比三项控制均被拒绝，且未发出任何浏览器调试请求。

两版本各 200 个数学块、200 个引用，预热两次，再测 150 次刷新／序列化，七个采样点。每轮要求原 HTML 不变，编号块和引用数量一致；清理后要求临时文档数量恢复。浏览器堆来自整个隔离目标，不是专属于该 iframe 的占用。

## 实测

| 隔离目标 | 旧数组：局部 DOM／堆变化 | 新查找表：局部 DOM／堆变化 |
| --- | --- | --- |
| Headless Chrome | 始终 2,401 节点；+48,080 字节 | 始终 2,401 节点；+47,992 字节 |
| 实际 Qt WebEngine 离屏 | 始终 2,401 节点；−811,612 字节 | 始终 2,401 节点；+37,856 字节 |

两个目标、两个版本的七个采样均保留 200 块／200 引用与原文；临时文档均从一份增至两份、清理后恢复一份。Qt 自有进程正常退出，原 DOM 47 项／边界 35 项和实际编辑器宿主 70 项仍通过。堆变化含运行时预热／回收噪声，不设一个任意字节阈值当作“泄漏通过”，也不把负数当作优化收益。

本轮没有发现该局部查找表导致持续 DOM 累积的证据，因此不为它添加全局缓存、强制回收或产品清理逻辑。当前测量 iframe 的序列化器为合成桩，宿主原编辑器另行检查；这不是完整编辑器、整 App、GPU、常驻内存或长期用户笔记的泄漏验收。

## 保留边界

开发诊断仍要求显式开发可执行文件，拒绝 Applications 安装路径，默认离屏，仅连接自己的临时调试端口。本轮不生成 PDF、不请求网络／账号、不读取笔记；离屏图形诊断保留，不冒称原生焦点或 GPU 全面验收。第三十五轮完整非前台 19 组／715 项是最近产品回归，本轮没有重复冒记为新整体回归。
