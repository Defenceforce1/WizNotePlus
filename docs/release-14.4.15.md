# 14.4.15 — 个人自用版群组管理入口整理与 CSS 说明

日期：2026-10-15。基于已交付的 14.4.14，用户新报点击个人群组后卡顿，并授权核查和清理不必要功能；不改已有 Markdown、CSS、数学、旧 PDF、同步、退出、名称或资料路径。

## 故障与上游功能

用户报告是约 17 秒的 hang，不是报告已经证明的笔记保存崩溃。主线程经过 `WizCategoryView::on_action_manageBiz`、`manageBiz`、`WizShowWebDialogWithToken` 和内嵌 WebEngine。采样很短，只能定位入口／路径，不能独立证明服务器故障或所有底层网页引擎原因。

上游基线 `3cae06fbd0eaa5147e5b307a428af359bceb47f5` 的 `WizActions.cpp` 已有 Personal Groups，`WizCategoryView.cpp` 已有上述管理动作；分类显示没有设置时默认为可见。它不是本分支新增功能。是否有群组和管理权限取决于账号／服务数据；没有启动用户的旧 Intel App、取得真实令牌或打开正式管理页，不宣称当前官方网页可用或用户已开通服务。

## 本次清理范围

Apple Silicon 个人自用构建将 `groupAdministrationEnabled` 置为 false：

- 隐藏群组／团队信息和管理动作。
- 移除创建团队推广链接、分组标题上的创建按钮和团队续费／管理附加按钮。
- 7 个创建／信息／管理函数在生成 URL／请求令牌／创建 WebEngine 前返回；空团队上下文菜单不再弹出。直接调用也不能绕过 UI 隐藏。
- 不删除群组目录、数据库、笔记、账号、权限或同步代码；已有群组的浏览和侧栏显示开关保留，未读提示逻辑保留。

其他平台／非独立构建保留原行为，未重构所有内嵌网页对话框，也未把账号令牌自动转交外部浏览器。本版是去掉个人用户不需要的入口，不是修复官方团队服务或保证所有 WebEngine hang 已解决。
