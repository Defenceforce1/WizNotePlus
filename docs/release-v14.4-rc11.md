# 主 App 14.4.11 自用候选

日期：2026-10-15。只更新主 App，独立剪藏器继续暂缓。保留当前资料库、账号兼容、Markdown 输入方式、自定义 CSS／数学引用、原始导入导出与旧另存为 PDF。延续 arm64 精简包、免费 ad-hoc 签名、未公证路线。

## 修改

- 移除正常主窗口的 8849 本机配对服务、“连接原生网页剪藏器”菜单和对应入口。旧剪藏器 8848 接口不变。8849 原实现仅作为隔离回归探针编译，不在正常启动实例化；不删除旧配对文件或用户数据，不修改独立剪藏器。
- 最后同步网络阶段总预算由 20 秒改为 5 秒（包含已有同步的等待）。独立完成信号不受重复离线 UI 提示抑制影响，明确失败不再空等。先确认所有本地保存，失败仍取消退出并提示；超时停止网络重试，之后按原顺序清理。5 秒不是整个保存和析构的时限，旧网页引擎清理 hang 的所有场景仍未确认解决。
- 原 Cleaning on Quit 窗口、11 个阶段及取消动作保持，清理开始立即显示。仍没有新增“最后同步／本地保存”弹窗。
- 接通原“拼写检查（仅英文）”开关与富文本／Markdown 可编辑正文；无需换编辑器、不自动纠错，正文错词可右键选建议。更新开关对标签页及独立笔记窗口生效。默认保持旧设置值，用户在偏好设置中自行开启。
- 编辑／阅读切换、编辑器重置后保持开关；拼写检查用到的临时属性在保存时恢复，不写入 HTML 或 Markdown。可识别的代码元素、渲染公式不检查；Markdown 原始代码／LaTeX 命令仍可能被词典标记，不是语法或中文校对。

## 数据目录

默认个人资料库为 `/Users/当前用户名/Library/Application Support/WizNotePlus-AppleSilicon`。Finder 的“前往文件夹”（⌘⇧G）可输入此路径。账号、笔记和设置均在其下；不是 App 安装包目录。不要在 App 运行时移动／删除数据库；完整备份应在退出并确认同步／本地保存状态后进行。旧版默认 `~/.wiznote` 仍独立，不自动迁移或覆盖。
