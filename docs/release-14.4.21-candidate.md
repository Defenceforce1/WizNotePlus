## 相对 14.4.20 的改进

- 修正后台账号助手在所属对象销毁后的回调访问，并在登录取消／提前返回时完成线程清理。
- 保存、标题、粘贴、字体状态、字数、邮件地址、帮助／设置窗口、渲染错误、手写／SVG 等延迟结果按所属窗口、页面和文档代际隔离。
- 私有服务器端点缓存使用本次服务器／语言快照和代际保护，网络等待不持全局锁。
- 大量数学块的装饰查找使用局部映射，保持原文、编号、锚点和解析规则。
- 警告、单 OK 错误和单 OK 信息提示在父窗口关闭时不再保留无效栈对象；提示后的少数 UI 动作重新检查所属窗口。
- 无效或过期的 Markdown 正文回调不再触碰已有导出文件；有效正文之后的资源事务仍是已知未完成项。
- 私有服务器搜索超时提示的主队列闭包绑定登录窗口寿命，保留计时器、等待框、UDP 清理及提示内容。
- 延续 14.4.20 的任务队列修补、14.4.19 的 PDF 目标坐标与离屏 Metal 纹理所有权修补，以及本地保存优先／退出同步连续三秒无进展截止。
