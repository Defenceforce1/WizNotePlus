# WizNotePlus Apple Silicon 14.4.13

2026-10-15，主 App 稳定性收尾。用户日志显示同步完成，但仍有跨线程网络对象警告；外部编辑器设置不能消除内置预览／初次加载时的提前调用。

## 修复

- 头像下载不再复用跨两个共享网络工作线程的下载器／QNetworkAccessManager。每个任务在自己的线程创建栈下载器，每次请求创建局部网络管理器，并在原线程销毁。请求仍使用原 GUID 接口、安全策略、超时、原缓存命名和失败保留旧头像机制。
- 任务只捕获请求快照、独立取消标记及 UI 结果弱引用，不在后台解引用页面／主机。信号经应用分发器排队回 GUI 线程，才更新缓存、推进队列和发出通知；主机销毁／退出后的晚到信号丢弃。没有新增强杀线程或修改同步退出预算。
- 富文本字号下拉框改用 Qt 6 有效的 textActivated 强类型信号连接原槽，保留原字号映射和编辑命令。
- 编辑器初始模式明确设为阅读态，不再读取未初始化的枚举值；初始化记录仅存在于运行时 window。页面未初始化时不调用聚焦、模式切换、重置修改标记、撤销／重做或 JS 修改查询；加载后的模式仍由已有初始化流程应用，不改输入引擎、笔记源或外部编辑器设置。C++ 已修改标记优先保留，标记内容为已修改不再重置 JS 原始内容基线。
- 没有删除或屏蔽控制台错误日志；真正的编辑器脚本加载失败仍保留诊断，不把日志安静当作资源加载成功。
