# WizNotePlus — Apple Silicon 发布候选版 v14.4-rc1

日期：2026-10-14。基础版本保留 2.12.0，独立资料库与 v14.3 相同。本版以正式使用前的安全修复和回归为主，不增加编辑功能。

## 已修改

- 移除 macOS 上继承的关闭服务器证书验证设置。Qt 网络连接使用系统信任证书，验证服务器身份，最低 TLS 1.2；不会忽略证书错误或降级重试。
- Apple Silicon 的账号 JSON 请求、服务发现、笔记／附件资源下载和分块上传等核心同步路径拒绝明文 HTTP。登录自建服务需要有效的 HTTPS 地址；不自动把 HTTP 改为 HTTPS，不悄悄降低验证要求。
- 携带账号凭据的请求只能跟随同一来源的重定向；笔记资源允许 HTTPS CDN 重定向，拒绝 HTTPS 到 HTTP。
- 日志网址移除用户信息、查询参数和片段，移除一处直接输出令牌的旧日志。此项不意味着所有日志或笔记正文都已完成隐私审计。
- 修复 Qt 6 网络错误信号接线，记录正确错误信息；已完成的请求不再等待不存在的后续信号。
- 打包脚本新增可选 Developer ID 签名入口，并提供明确要求有效签名的公证脚本。没有证书时不会伪装为签名或公证完成。

原 Markdown 编辑习惯、CSS 设置键与模板、数学编号和“另存为 PDF”实现保持不变，不转换笔记数据库或加密格式。没有加入 AI、WebDAV、团队、数学宏、完整 TeX 或新打印功能。

## 验证边界

本机原生构建、8 组隔离自动测试及 28 项网络检查已通过。有效、未知 CA、过期和主机名不匹配的证书使用临时本地 HTTPS 服务测试；生产 JSON 和笔记资源下载入口也在其中。临时测试信任不写入系统钥匙串。

修复后的构建成功完成 api.wiz.cn 和 as.wiz.cn 的证书验证握手；只握手，没有发送账号、令牌、笔记或登录请求。这不等于登录或同步测试完成。

最终打包、窗口检查、归档校验与 GitHub 云端结果以随包验证记录为准，不预先声明完成。

## 原账号如何启用

原账号与原同步协议保留，不需注册新账号。但登录后云端笔记仍是原来的那一份，本地独立目录不能隔离云端修改和删除。

建议先在旧客户端完成同步并备份重要笔记和完整资料库，然后完全退出旧客户端。不要把测试账号的数据合并进正式账号目录。先验证少量非重要笔记的下载、正文、附件、标签与修改同步，确认无误后逐步使用。不要一开始批量移动或删除笔记，也不要同时运行两套同账号客户端。

本轮没有代理登录真实账号或读取真实笔记。登录、双向同步、冲突、加密笔记、断网重试和长期运行仍未完整验证，暂不能承诺主账号安全迁移全部通过。

## 正式发行尚缺

1. Developer ID 签名与 Apple 公证，以及签名后 Qt WebEngine 与系统安全检查。当前电脑未发现有效签名身份。
2. 原账号的受控真实同步验证，以及复杂数据与长期使用测试。
3. 全部编辑器、字体、图片、Qt／Chromium 等第三方资源的版本、来源及对应源码／许可完整性核查。

PDF 定义／定理引用的垂直定位偏移、旧 Safari 剪藏器登录和其他 App 的真实导入仍保留为已知限制。当前验证系统是 macOS 27.0.1；不代表未来 macOS 28 认证。
