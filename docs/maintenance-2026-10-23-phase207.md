# 第207轮 有边界的综合审查与合并优化

用户授权自动推进全面普通优化。本轮按当前自用范围收口，不把“所有可能”解释为
无限新增功能。审查六类：渲染吞吐、异步切换、资源生命周期、缩略图缓存所有权、
打包冗余和交接记录。排除仍有效的普通Markdown保存失败排查、Touch ID／续签、
未经权威契约的证书创建、VoiceOver、网络／安全测试、真实账号及受限组件改动。

## 完成的修改

1. 大量裸公式原文恢复：原实现逐块线性查找原文，改为每次转换的临时Map索引。
   原文和旧读者首次行分隔符展开两种键按原顺序写入，冲突保持第一次匹配；不
   做全局缓存，不跨笔记保留正文。1800段合成对照89.25→7.55ms，包含夹具初始化，
   不是日常完整笔记打开提速；普通、代码、引用容器及分隔符碰撞输出一致。
2. 数学加载期间的模式编排：等当前补充渲染结束后，只派发最新模式请求；过期
   派发／完成不执行，不覆盖新请求状态或清理新pending。终态pagehide撤销排队
   请求并释放监听器；BFCache暂存不永久停用编辑。旧实现复现8项控制失败。
3. 原生联测补出已是阅读模式时底层off不再回调的问题。仅对等待数学后、已处于
   同一Markdown阅读模式的已知选项，继续自有剩余数学工作，不重复请求底层切换。
   初次原生22项中4项失败留证，补此窄修后22项全通过；不把模拟控制通过当整链通过。
4. 依赖完成／失败／超时清除自有deadline与script事件闭包，只有相同loader实例
   能清全局引用，失败允许新尝试。未声称可取消已经开始执行的第三方脚本，也
   不强行销毁活动渲染／保存或清未保存DOM来换内存数字。
5. 更新过时的next-build／production-package当前头部；203只保留为历史回归包，
   不继续推荐。旧阶段记录保留，不将历史未完成／旧心跳状态当当前待办。
