# 标签栏重复绘制遍历减少

2026-11-02，六轮优化第五轮。关闭按钮自身的Paint事件不再触发全标签遍历，仍由
标签栏Paint检查布局／滚动后的悬停状态；鼠标、悬停、布局变化继续合并更新，
锁定／解锁仍同步更新。没有改变按钮画法、正常关闭或笔记保存。

隔离的实际标签栏同二进制参考／候选比较，一次标签栏绘制全扫描6→1，像素一致；
300次合成MouseMove仍合并一次。具体次数取决于可见标签数，不是整App加速比例。

精确候选进入源码后直接编译实际WizMainTabBrowser.cpp（无诊断开关／计数），
链接当前主窗口隔离夹具，10项相关检查通过：绘制一致、锁定、解锁、合成鼠标、
当前标签、标签移动、尺寸改变、正常关闭及排队更新后的所有者销毁安全。
使用当前正式运行时与隐藏Cocoa窗口，不宣称前台触控板、长期用户会话或全客户端验收。
未触及正文和导出，因此未重跑公式／PDF矩阵。
