# v14.4-rc5：搜索布局与头像上传提示

搜索和新建笔记不交换位置。搜索框缩至 300 像素宽、仍为 26 像素高；内部透明，聚焦后也显示同一顶栏底色。减少前方留白，在账号和同步按钮允许的空间内对齐笔记列表左边缘。列表栏宽调整后会重新协调，不强行重叠控件。顶栏高 44 像素，红黄绿大小和水平间距不改。

头像上传增加等待状态与明确的错误提示，保留实际 HTTP 状态及网络错误码，不显示登录凭据或原始服务响应。图片在内存中准备为 100×100 PNG，不发送本地路径，不遗留随机临时图片。保留原 token／avatar 字段；仅明确的服务成功结果才触发头像刷新。证书验证保留，不自动跟随上传重定向、不自动重传凭据。

用户报告的 499 是 Qt UnknownServerError，不等于 HTTP 499。本轮不带账号凭据的公开检查得到 wizas=https://as.wiz.cn/wizas；对应旧头像地址的 HEAD 请求返回 HTTP 502，新前缀地址 HEAD 返回 404。旧接口或网关故障是合理推测，不是经认证 POST 的最终结论。没有改用未经验证的新接口，没有发送真实账号凭据或上传用户图片；真实服务上传仍待试用确认。

本地 HTTPS 合成测试覆盖头像请求、错误、认证拒绝、假成功响应、重定向及失效证书。既有笔记数据、Markdown、CSS、数学编号和原另存为 PDF 保持不变。

发布准备另补 MathJax 2.7.6 与 jQuery 3.3.1 的官方完整许可文本，并核查 WOFF 元数据。字体／素材、部分依赖与对应源码缺口仍在；系统仍无有效代码签名身份，无法完成 Developer ID 签名和公证。仍为发布候选版，不是正式公开版本。
