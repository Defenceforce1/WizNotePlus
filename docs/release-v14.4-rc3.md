# v14.4-rc3：顶栏留白与按钮间距

根据试用反馈，将单行顶栏从 34 像素加高到 44 像素。搜索框仍为 26 像素高、340 像素宽，不把输入框一起放大。

账号、同步、搜索、新建笔记之间的间距稍微增加。红黄绿按钮仍是系统原生控件，按顶栏高度居中；保留 Qt Cocoa 代理和事件机制，不安装旧 FramelessHelper 代理，不修改系统方法。全屏期间由系统管理按钮，退出后恢复居中布局。

顶栏空白处使用 Qt 的系统窗口移动接口拖动窗口。其他对话框不采用这套顶栏。笔记数据、账号、Markdown、CSS、数学编号和原另存为 PDF 均不改动。

隔离回归检查包括单行顶栏高度、控件对齐、原生点击命中、最小化、全屏、模态恢复、关闭重开及全屏关闭后的恢复。实际鼠标拖动、所有屏幕及缩放组合尚需试用确认；电脑控制权限未就绪，不需要安装 Chrome 扩展。

仍是临时签名的候选版本，正式签名、公证、完整第三方许可与对应源码审计和长期真实账号同步验证未完成。
