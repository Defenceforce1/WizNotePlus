# v14.4-rc8：多笔记标签页关闭按钮

多笔记关闭按钮改为常显，不再依赖 HoverEnter/HoverMove/HoverLeave 维护可见性。创建、切换、重排、关闭邻近标签后仍可见；锁定标签显示原锁图标并保留“不允许关闭”的保护。按钮尺寸至少 16×16，不修改笔记保存或 RequestClose 流程。

隔离主窗口回归增加八个长标题页，检查所有关闭按钮、切换/重排、锁定防关闭，以及点击重排后的关闭按钮只关闭对应页面。原有窗口、搜索、CSS、数学和启动回归保留。测试不打开真实账号。

用户提供的 2026-10-14 16:18 报告是 hang（约 18 秒），主线程在 QApplication 析构后的 QtWebEngine 清理阶段等待；不是异常崩溃报告，也不是标签按钮绘制调用栈。不能由此证明数据损坏、具体 Chromium 根因或性能问题已修复。本版只修复按钮可见性，退出卡顿需另行隔离复现；不通过强制终止、跳过析构或清空用户缓存掩盖问题。

三个候选功能（CSS 方案管理、引用导航、全局附件检查）暂缓。后续新功能优先原生网页剪藏，见 web-clipper-modernization.md。当前旧剪藏器保持原样，本版没有更新或替换它。

仍为临时签名候选版；第三方素材/依赖权利核查、Developer ID 签名、公证和长期真实同步验证仍未完成。
