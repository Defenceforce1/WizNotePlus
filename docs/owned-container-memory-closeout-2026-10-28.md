## 从空间来源到具体候选

只读核对同版Blink公开源码：QueryAll把匹配结果放入HeapVector，再转为静态节点
列表；MutationObserver的记录列表、child-list增删节点列表也使用HeapVector。
这些类型共享可压缩向量存储空间，因此308的77.625MiB不能直接归到某个JS函数。
选择器缓存保存的是选择器查询，不是每次结果列表；自有NodeList主要为同步局部。
定理拆分的子节点数组有恢复原顺序的义务，不能为降数值删除。308拼写记录大／小页
为131／4，尚无持续追加旧节点注册表的证据，不把这些界限当全部累计分配上限。

确认一条具体自有分配路径：WizSetSpellCheck中的观察器监听整篇childList，回调仅
调度全量拼写属性刷新，不消费记录内容。同步序列化会附着、移除临时DOM；这些
增删记录可在微任务交付前保持临时节点。候选只在已确认观察根仍是当前body时，
暂时断开该观察器、完成原序列化与原finally刷新，再观察原根；嵌套深度及异常顺序
保留，根以WeakRef记录，不增加跨笔记强持有。只修改项目独立资源副本的自有helper，
不改变编辑器内核、保存逻辑、GC或共享profile。
