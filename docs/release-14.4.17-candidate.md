## 本轮改进

- 屏幕内的定理／定义引用跳转增加短暂目标轮廓和顶部留白；不改原文，不把定位样式写进笔记或 PDF。
- 修复反复装饰引用时空文本节点累积、原样式属性还原及公式边界识别，避免将复合公式／代码中的引用误当作普通正文引用。保留现有 Markdown 和 MathJax 引擎。
- PDF 输出明确使用已存页面单位，拒绝无效布局；异步输出通过临时文件原子提交，失败不先删除已有文件。毫米单位恢复正确含义，会改变旧错误单位造成的实际边距／分页；不承诺与 14.4.16 逐像素一致。没有额外打印窗口或独立打印 CSS。
- 保留加载／保存通知，避免队列提前通知丢失；不同笔记页不互相覆盖待加载请求。结果增加请求页和序号，旧结果、同笔记另一窗口的结果及销毁页面的结果不再误用。
- 保存、初始化和模式切换的异步回调检查页面存活及代际；严格确认实际编辑／阅读模式。临时 HTML 原子写入，缺失／失败不再被视为保存成功；实际原保存队列及磁盘结果仍需确认。
- 原生编辑器拒绝过期连接回调；路径及账号显示名用 JSON 传入，保留特殊字符而不变成脚本。拼写检查的临时属性在原文序列化和原编辑／阅读切换中正确还原。
- 退出先确认本地保存，再尝试最后同步。连接／启动等待 3 秒；开始后有进展就继续到完成，失败或连续 10 秒无进展才停止等待。不是上传总时限。退出准备时暂停普通输入，提交退出前再确认本地保存；失败恢复编辑。保留原清理进度／取消，不加确认弹窗或无限重试。
- 编辑状态检查线程和网络对象在所属线程正常清理，不用强行终止线程换取退出速度。

## 源码包和重建

候选源码包按开发分支的完整 Git 树逐文件校验，不按本地旧 HEAD 或整个脏目录打包。包含三个直接子模块及 Gumbo 的两个嵌套测试依赖，共五个固定提交的原始源码；不夹带其工作区补丁、私人资料、日志、编译缓存或 Qt SDK。父项目的 `cmake/patches/framelesshelper-qt6.patch` 保留，已在归档解出的原始子模块中通过 `git apply --check`，用于重建时明确应用。

从源码包重建时，保持 Git 可用，按 [arm64 构建说明](macos-arm64.md) 配置 Qt 6.11.3、CMake／Ninja 和带 CVE-2023-50980 补丁的 Crypto++ 8.9.0。没有 `.git` 的源码包不会执行子模块更新，但 CMake 会使用 Git 应用已跟踪的 FramelessHelper 补丁。如果显式使用 `-DCMAKE_DISABLE_FIND_PACKAGE_Git=ON`，须先在 `src/libs/3rdparty/framelesshelper` 内对该补丁执行 `git apply --check` 和 `git apply`，不要跳过补丁构建。Qt SDK 及其他外部依赖不包含在源码包中；许可证说明随 App 保留，并不等于完整公开发行审核已经完成。
