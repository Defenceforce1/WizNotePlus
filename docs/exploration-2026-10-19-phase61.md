# 第六十一轮：暂存原型的文件名与隐藏资源兼容

2026-10-19。只改测试原型，产品仍为第五十九轮；不打包、不安装。

兼容性对照发现的是**未集成原型的缺陷**，不是现用 App 的新故障：用户选择无扩展名的 `previous-resources`／`returned-resources` 时，暂存 HTML 会和内部备份／回退路径冲突；原型复制旧资源时沿用通用函数的隐藏文件过滤，又会在整体换目录时遗漏旧隐藏文件。

先保留实际负对照：14 项有 **6 项失败**，正常退出 1。随后只在测试原型修正：

- 用户内容放入单独子目录，内部备份／回退路径与用户文件名隔离。
- 原资源快照显式保留隐藏普通文件及隐藏子目录，不全局修改 `WizCopyFolder`，实际档案导出的原复制规则保持不动。
- 未知符号链接、FIFO 等非常规旧资源明确拒绝，目标正文和资源不动；不跟随链接或打开可能阻塞的特殊文件。这只是原型策略，不改产品的既有行为。

最终文件名／隐藏资源兼容 **20 项**、正常及失败回退 **35 项**，各在 ASan／UBSan 下连续五轮通过。Unicode、`&`／尖括号、点前缀／无扩展名、隐藏图片与嵌套隐藏目录、真实临时链接及 FIFO 均有断言；Qt 未插桩、泄漏检查关闭。原型哈希与初始失败对照分别记录，未将失败覆盖掉。

元数据／扩展属性保真、真实资料包与主窗口衔接、一般并发和断电恢复仍未验收，不接入资源重构。第五十九轮产品的 836 项是历史完整回归，本轮没有重新借用为整体验收；安装副本和资料不动。
