# 第二十九轮：异步账号助手与提前返回清理

2026-10-18。后续源码为 **14.4.21 开发版**；用户最新要求暂停安装包制作，继续核查优化。本轮不生成新的安装镜像、部署包或交付源码归档，不安装。14.4.20 候选、现用 App 和回退均固定保留。

## 原实现的独立失败对照

`WizAsyncApi` 是注册窗口及消息列表使用的内部 UI 助手。原方法把隐含 `this` 指针交给后台任务：窗口销毁后，尚未开始的任务或正在等待响应的任务仍可写入该对象的错误字段并发出信号。

复制原实现，只将服务器／令牌依赖替换为不会联网的假响应，保持原对象访问逻辑不变。独立 AddressSanitizer 子进程实际检出两种 **heap-use-after-free**：入队后、尚未开始时销毁对象；请求执行中销毁对象。第三个对照确认存活对象的错误状态和完成信号仍从工作线程处理，而非 UI 线程。

这些子进程只处理合成字符串，没有真实网址、套接字、账号发现、凭据或资料访问。原实现的崩溃／失败日志留本机，不是现用 App 的新崩溃报告，也不把测试假响应称为真实云端协议验证。

## 修补

- 后台只持有不可变请求参数、取消标记和结果值，不在工作线程读取 UI 对象成员。
- 对象销毁先设置取消标记；尚未开始则不请求，已开始则不再回写销毁对象。完成结果交给应用线程，只有存活对象才更新错误状态和发信号。
- 完成信号允许同步删除对象，发出后不再访问它；成功结果清除旧错误，初始错误状态确定为零。
- 移除该类从未使用的 `QNetworkAccessManager` 成员，实际请求仍使用原服务器实现和原协议，不新增账号、认证或网络功能。
- 增加启动作用域的队列清理：登录取消、数据库打开失败等提前返回时，先请求取消网络，再等待任务退出，保证应用分发器仍存活。正常主窗口仍保留原十一阶段退出清理；不缩短本地保存、不改变同步三秒无进展策略。

生产 App 不编译假传输定义；只有独立单元目标替换网络依赖。类仍限于原有的应用线程调用点，不声称支持从任意线程创建／删除 UI 助手。

## 当前验证

独立实际源码的 AddressSanitizer／UndefinedBehaviorSanitizer **10 个场景通过**：初始状态、开始前删除、执行中删除、存活对象线程归属、消息读删与错误清除、空令牌、回调中删除、已排队回调失效、48 个并发回复，以及提前返回的取消／等待顺序。Qt 本身不是全量消毒构建，泄漏检测关闭，不将此称为所有内存或数据竞争已排除。

扩展夹具初次使用了 Qt 的 `signals` 宏作为局部变量名，编译失败；修正为普通计数名称，保留该失败，不归因产品。第一次替换源文件的补丁格式无效，也未据此声称已应用修补。

排除原生拼写窗口的 **18 组／669 项全部通过**。输入保护后的拼写夹具另在离屏模式通过全部 **34 项**，确实调用浏览器检查器并保留原文；它不能替代 Cocoa 前台验收。离屏运行出现图形上下文丢失／mailbox 诊断，保留记录，不将其作为正常原生 GPU 渲染验收，也不因此修改产品图形后端。十个异步内存安全场景连续八轮均通过。
