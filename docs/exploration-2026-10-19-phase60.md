# 第六十轮：回退失败时保留恢复资料的受控验证

2026-10-19。产品源码仍为第五十九轮，无新增功能／部署／安装；继续只扩展测试专用暂存原型。

之前只验证正常回退，不能据此保证“回退也失败”时不会丢备份。这次增加测试专用故障注入点，仍由实际文件权限、QDir 重命名和 QSaveFile 取消决定失败：

1. 临时暂存目录不可写，使换回新资源的步骤失败；恢复权限后核对 helper 已返回，而旧资源备份仍完整保留，旧 Markdown 未变，错误包含明确的保留位置。
2. 新资源已经退回暂存区，再在原目录位置放入合成阻挡文件，使旧资源恢复失败；核对原型不覆盖未知阻挡文件，旧资源和退回的新资源两份都保留，旧 Markdown 未变。

扩展后 **35 项在 ASan／UBSan 下连续五轮通过**，包含原 27 项及上述八项。Qt 未插桩，泄漏检查关闭。新增断言也确认失败后资源并未恢复时不声称已经恢复；只承诺测试中的备份保留。全部权限更改只在自动生成的临时目录内并已恢复，外层测试临时目录在检查后正常清理自己的合成资料。

这不是通用并发写入安全、断电／崩溃后自动恢复、恢复界面或真实资料包端到端验收。故障注入回调和整个暂存原型均不链接主程序；没有修改产品通用复制函数，也未把开发目录构建安装到应用程序。

第五十九轮源码已通过 GitHub 插件备份／读回：`4723d3df0ec2b2ebd9a1598b91a13debf553be5d`，整树 2,595 项、所选 201 源文件一致；完整 20 组／836 项属于该轮产品结果，本轮不借用为新暂存原型的整体验收。后续继续检查资源事务原型的文件名、阶段转换和真实调用衔接，不因局部通过而提前集成或制作安装包。
