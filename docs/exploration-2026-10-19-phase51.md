# 第五十一轮：标签边界的兼容回归

2026-10-19，只有测试和记录变更，产品源码保持第五十轮版本。仍暂停安装包和安装；系统锁屏期间不运行前台检查。

在原 47 项数学装饰测试上增加 28 项：十一种合法标签（含对象属性同名、路径标点和 127／128 字符边界）、十二种现有语法外标签、三种重复标签、两种已有目标 ID 冲突。合法标签反复预览／序列化后核对原 HTML、样式、ID 与节点数；无效标签保持原文本，重复／碰撞不产生劫持目标的引用。没有扩大标签语法，中文标签仍不在现有语法内。

独立浏览器原有 **47 项**先通过；扩展后的首轮 **73 项通过、两项失败**。检查发现夹具把序列化后自动重建的预览 DOM 误当作裸原文，修正为分别验证链接／目标、序列化字符串，再明确清除装饰后核对原 DOM。没有因此修改产品渲染逻辑。

首轮 Qt 同样保留这两项夹具失败；还漏设了当前实现应为零的旧文本增长对照预期，不能把其 `expectedProbeBehavior=false` 当作产品内存增长。最终明确 `WIZNOTE_EXPECT_TEXT_GROWTH=0` 并重新运行，不修改工具的历史基线默认值。

最终结果：

- 独立隔离浏览器 **75 项通过**，没有脚本异常；
- 主 App 实际 Qt WebEngine：**75 项 DOM／35 项公式边界／70 项原阅读器宿主检查通过**，正常退出，候选回归和预期行为均为 true，原文保持；
- 实际加载日志确认使用隔离的干净修补引擎；产品 helper SHA256 仍为 `ea620372dd4a22d0aa1afa17b7d4fd200d945e44976ebeefa426b97737c9d9b7`，未改动。

这些是合成 DOM／阅读器兼容结果，不是新增 PDF 几何、原生窗口或 Metal 压力验收。本轮没有重新构建产品，也不把第五十轮完整 20 组／830 项当成本轮重新跑过。旧失败、实际引擎加载路径和原始日志只留本机。
