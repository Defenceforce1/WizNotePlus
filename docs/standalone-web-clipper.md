# 独立网页剪藏器 0.2.0 候选

日期：2026-10-14。此次只修改／构建剪藏器，主客户端保持 rc10，旧官方 Intel 剪藏器不动。

## 最新反馈与暂缓决定

用户实际反馈为“效果勉强可以，但很多瑕疵”，截图在已显示的数学符号／公式旁重复出现缺图占位文字，影响正文阅读。本机预览和合成测试通过不代表这一实际页面的资源／公式保真已解决；未仅凭截图确定具体失败原因。

用户要求下次改为只推送、不轮询保存结果，并取消查询不到结果时的持续等待／阻塞。仍需保留上传错误提示，区分“请求已接收”和“保存已完成”，不得无依据显示保存成功或自动重复提交。本次只记录，不改程序；0.2.0 的轮询和未确认任务逻辑目前仍存在。

剪藏器开发及云端验收暂缓，优先彻底收尾主 App。后续再处理上述推送策略、重复公式／缺图占位和复杂排版。两者分别构建与发行，不用重建主软件来改剪藏器，也不把剪藏完成列为主 App 自用版的前置条件。

## 官方保存格式核查

不是 Markdown。已读取 [WizTeam 官方资源收集代码](https://github.com/WizTeam/WizQTClient/blob/master/src/html/WizHtmlCollector.cpp)：HTML 中的图片等资源被收集，路径指向 `index_files/`，HTML 与资源再经 `html2Zip` 写成 ZIP 原始笔记容器。当前上游客户端同步代码也将原始包中的主 HTML 和资源清单拆出，分别传输；见 [官方同步实现](https://github.com/WizTeam/WizQTClient/blob/master/src/sync/WizKMServer.cpp)。因此不能把本地 ZIP 表述成所有服务端上传请求都直接上传同一个 ZIP 文件。

2026-10-14 无账号只读请求 [官方接口发现](https://api.wiz.cn/?p=wiz&c=webclipper_openapi_url&protocol=https) 返回 code 200，仍列出 `https://note.wiz.cn/ks/gather`、`/ks/gather/status`、登录和分类地址。两个浏览器参考项目描述了 HTML frame／Base64、资源收集、后台任务与状态查询；新代码独立编写其协议，不直接复用许可链未充分确认的参考源码。

尚未取得旧 Mac 剪藏器完整源代码／当前服务器内部实现；官方旧客户端的容器格式、发现服务返回值与参考浏览器行为不能冒充旧 Mac 1.0.5 和所有当前服务器的逐项实测。发现地址有响应也不证明登录和写入端点实际可用。

旧新剪藏器 0.1.1 也保存 HTML，并没有转 Markdown；丢失图片和公式的原因是资源处理／静态化不完整：无法经 canvas 读取的图片只保留链接，SVG／canvas 被占位；MathJax／KaTeX 显示树依赖网页 CSS，而辅助 MathML 本身带隐藏样式。0.2.0 针对这些问题捕获可见静态 MathML、嵌入已加载图片并补充受限远程图片下载。

## 使用

1. 安装／启用“WizNotePlus 网页剪藏”系统分享扩展；不用安装主软件，也不用 Chrome 插件。
2. Safari 分享网页到该扩展，选默认“直接上传为知云端”，在新剪藏器中自行登录原账号。密码不保存；“记住登录”默认关闭。
3. 核对账号和个人文件夹。可先点“版式预览”检查图片、公式，不上传。
4. 保存；只有服务器任务完成才显示服务器已确认，不将进入队列当作已保存。
5. 以后任一客户端登录同一账号并正常同步。尚需验证同步后的内容是否与本机预览一致。

本轮没有登录真实账号，也没有上传用户网页。云端需要联网；无网络时不声明已经上传、无独立离线队列。主客户端本机保存入口仍保留，但需要 rc10 运行，且原桥接 2 MB／MathML 白名单限制没有改变。

## 安装与回退

独立安装包只含剪藏器 App、对应独立源码和说明，没有 Qt／主客户端。免费 Apple Development 签名，未公证；另一台 Mac 的加载须实测，不能承诺直接拖入必然可用。不要关闭系统保护、导出私钥或将密码发到聊天。

本机从 0.1.1 升级为 0.2.0，0.1.1 已完整留在工作目录 outputs/clipper-v0.2.0-checks/installed-0.1.1-backup。只处理本项目的开发注册，未卸载／启动／注销旧官方剪藏器。回退需要用该副本替换同名新 App 并重新启用系统分享入口，主客户端不需回退。

## 仍需验证／限制

- 实际账号登录、旧 gather 的新身份认证兼容性、服务器收集内嵌图片／MathML、任务完成及各客户端同步。
- 自己勾选记住登录后的钥匙串重启持久化，以及另一台 Mac 加载。
- 私有部署、多账号、标签／备注／正文提取、离线待上传暂未实现。
- 无辅助 MathML 的 SVG／canvas 公式、登录保护／HTTP／重定向图片可能无法嵌入；GIF 为首帧，大图会受尺寸和容量限制。
- 静态 MathML 不依赖原站脚本，但不能保证旧客户端或服务端清理器保留所有 MathML 属性；须检查同步结果。
- 图片会话不携带登录信息。域名／DNS 私网检查和限时限量已实现，不宣称完成恶意 DNS 重绑定防护或完整网络安全审计。
- 现有本机系统 HTTPS 转发代理会被沿用，避免误拒绝 VPN fake-IP；不更改代理／信任设置。无代理时仍执行公网 DNS 检查。固定上游 PNG 的真实下载、验证和嵌入已通过；不将一个图片测试推广成所有站点成功。
- 失败不自动重新 POST；保存任务编号可供后续查询。取消不撤销服务器已接受的任务，解除未确认提示前必须先核对服务器以避免重复。

本机 Safari 对用户指定的超理论坛页面已捕获 644 个静态公式，预览看到头像、求和、上下标和多行公式；这不是云端或所有网页验收。合成检查与失败日志保留，公开源码／包不包含账号、密码、令牌、用户笔记或个人崩溃报告。
