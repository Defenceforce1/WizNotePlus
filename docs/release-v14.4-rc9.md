# v14.4-rc9：自动隐藏与安全退出

关闭按钮恢复悬停显示、移开隐藏。只隐藏绘制和鼠标命中，不移除布局位置；切换、重排、滚动或关闭邻近页后重新判断指针所在页。锁图标继续显示，锁定页保护保留。

按用户确认的规则，菜单退出和 Dock/application 退出先检查本地保存；保存成功后尝试最后同步，网络阶段总等待上限 20 秒（含正在进行的同步）。保存失败取消退出，保留编辑窗口。网络不通、失败、用户选择“仅保存本地并退出”或超时后停止重试，保留待同步内容，下一次正常联网同步。该上限不是整个退出耗时的承诺，本地磁盘保存、线程收尾及 QtWebEngine 析构仍需要时间。

同步停止标志改为原子访问，停止线程时请求协作中断、停止定时器并唤醒等待。共享网络等待检测进程退出/线程中断并取消 reply；退出后的新请求被拒绝。编辑状态请求不再无限等待，改用同一可取消、有超时、验证 TLS 的通道。未改变正常笔记数据库格式或上传成功才更新状态的原逻辑。

保存线程停止时排空已提交队列，不丢弃待写笔记。检查保存状态不能掩盖未解决的失败笔记；失败时恢复编辑修改标记，避免把失败当作已上传。保存回调有界等待，不让超时回调持有失效的栈引用。当前主界面和独立笔记窗口都纳入退出前本地保存。

保留搜索布局、账号兼容、原有 Markdown 编辑习惯、CSS、数学标签/引用和原另存为 PDF。未加入额外打印、AI、WebDAV 或团队功能。旧 Intel App 和旧剪藏器不启动、不覆盖。

新增隔离退出自测：本地队列排空及逐笔记内容、保存失败、未解决错误、停止后拒绝同步任务、正常网络、线程取消、进程取消、不再发新请求、取消下载不覆盖已有内容。使用临时虚构资料库和 loopback，不断开整机网络、不登录正式账号。完整真实账号最终同步、故障恢复、多机安装和原先 QtWebEngine 析构 hang 仍需验证，不能将这些自测称为已解决所有退出故障。

免费开发证书的中间链已补齐：只从 Apple 官方下载 WWDR G3，先用系统现有 Apple Root 验证，再导入登录钥匙串；未改变证书信任策略、未导出私钥。原生剪藏宿主/分享扩展的开发签名构建成功，系统注册查询可识别独立测试扩展。它仍无剪藏保存功能，未验证 Safari 实际加载，不附入主程序发行包，也没有替换现有剪藏器。

主程序仍使用免费临时签名、未公证。DMG 包含完整运行依赖及安装说明，普通使用无需 Qt/Xcode。对应公开源码与许可随包提供。素材/依赖权利审计未完全结束；先供用户自用验证，不宣称为已公证或完成公开发行审计的正式版。

本轮打包后验证曾错误沿用 SDK 测试的 QT_QPA_PLATFORM=offscreen，导致两个隔离测试在 QApplication 初始化时 SIGABRT：最终包只携带正常 macOS 使用所需的 cocoa，而不携带 SDK 的 offscreen 插件。用户提交的新报告明确为代理启动的 wizShutdownSelfTest，不是正式账号使用。失败发生在数据库打开前，未读写真实账号。改用包内 cocoa 后两项均通过；新增 test-packaged.sh 固定原生插件并先检查存在性，避免重复错误。失败日志保留，不将其当作同步/数据故障，不上传私有原始报告。
