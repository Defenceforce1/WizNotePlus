- 以已安装 rc10（14.4.10）为基线，保持原账号与数据兼容、现有 Markdown 编辑方式、自定义 CSS／数学引用和旧另存为 PDF。

- 免费、未公证自用路线仍有效。稳定自用版与已公证／公开发行验收不是同一结论，不重新要求用户购买开发者会员。

- 已安装 rc10，rc9 回退副本保留。程序升级不主动移动／重写用户资料库。

## 接下来按顺序处理

1. 对照现有代码、用户反馈与测试记录，列出主 App 真正残留的缺陷；优先可能导致丢笔记、错误同步或无法退出的问题，不因收尾而随意重构已工作的功能。
2. 核查保存失败阻止退出、退出线程收尾、原 QtWebEngine 约 18 秒析构 hang 的剩余验证范围；使用合成账号和临时资料库，不强杀真实笔记进程、不关闭整台机器网络造故障。
3. 必要代码改动后只构建主 App，跑与改动相关的检查及主软件完整回归：窗口控制、标签页、搜索、Markdown／富文本、CSS／数学、旧 PDF、原始导入导出和启动／退出。
4. 提供主 App 独立 DMG，携带全部运行依赖、对应源码、校验码、安装／升级／回退与已知限制说明；剪藏器不塞回主程序包，不在只改文档时重复编译主 App。
5. 核实第三方素材／字体／压缩编辑器许可与 Qt 对应源码的剩余缺口，区分本机自用交付和 GitHub 公开二进制发行；不以未公证／测试标签免除许可要求。
6. 真实账号最终同步、保存失败交互、加密笔记／冲突、另一台没有开发依赖 Mac 的启动与编辑须按实际结果记录。需要用户操作时集中说明，不把隔离检查或一台机器的结果推广成已完成多机／云端验收。
