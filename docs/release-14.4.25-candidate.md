# WizNotePlus 14.4.25 Apple Silicon 自用候选

本版整合最新已验证源码，修复刚创建笔记时窗口认为处于阅读态、网页却仍在编辑
的问题。初始模式统一由窗口层按原权限和锁定规则决定，单次切换阅读即可渲染
裸 equation／align 等数学环境，保留 Markdown 原文。

## 主要变化

- “另存为 PDF”采用阅读宽度／A4 二级菜单，不记忆上次选择。修复已测长 multline
  正文与编号挤压；打印后恢复临时样式，普通正文及编号不整体缩小。
- 保留常用定理、命题、推论、证明等 LaTeX 风格环境及引用。
- 完善异步初始化、迟到通知、格式／插入命令、保存和退出协调，避免过期结果作用
  于新笔记；保存失败不清空未保存正文。
- 已知密码永久解除个人笔记加密需重新输入密码并明确确认，先保留完整加密归档。
  opt-in 受保护截图返回后需重新授权才插入。
- 设置命名、简体中文资源、群组默认只下载标题及账户设置相关修补纳入本版。
  正常账户头像更新／重开仍需要实际试用，不称所有账户服务已验收。

## 保留边界

正常 Touch ID 入口仍关闭；合法签名配置、首次兼容证书登记的权威服务契约和真实
系统认证验收尚未完成。没有密码恢复后门，不自动转换真实加密笔记。

持久 Markdown 导出恢复编译时仍为 OFF，自动开发任务保持暂停。VoiceOver 专项
按用户要求跳过，不删除通用键盘和无障碍名称。未解决的特殊文件名旧 HTML 资源
URL、历史离线账户夹具及断电／并发写者原子性限制仍保留。
