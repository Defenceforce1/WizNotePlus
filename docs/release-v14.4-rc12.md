# 主 App 14.4.12 稳定性修订

日期：2026-10-15。用户重新连接网络后确认同步恢复、断网退出通过、目前退出机制合适。本版只修后台评论任务的生命周期及两条界面警告，不改 14.4.11 的同步服务器／代理设置、退出策略与窗口、编辑方式、英文拼写检查、CSS／数学、原始导入导出和原另存为 PDF。

## 生命周期修复

此前崩溃报告显示退出清理期间一个后台线程在建立 QObject 信号连接时崩溃。旧评论任务以裸 this 捕获管理器，排队期间其所属笔记／标题栏可能已销毁；后台还直接读写管理器的 busy 状态。该风险与报告线程位置吻合，但不宣称已经复现真实账号的完整崩溃或证明它是唯一根因。原始报告、账号、机器标识和日志不发布。

- 工作任务只持有独立取消标记、请求值快照和弱引用。弱引用只在主线程结果投递时读取，后台不解引用页面管理器。
- 临时查询对象连接到生命周期覆盖网络池的应用分发器，不再连接可能已关闭的笔记对象。管理器析构即标记取消；排队任务在任何接口／令牌查询之前退出，运行中的晚到结果不再投给已关闭笔记。
- busy 预留和复位均在 UI 线程，避免网络池拥堵时为同一管理器重复排队；保留原查询节流与结果 GUID。
- 已开始的网络请求不新增强杀或全局网络设置；退出仍沿用已通过的保存优先与有界最后同步策略。

## 两条界面警告

- QMainWindow 继续用原有 centralWidget，不再尝试重复安装外层布局；普通对话框保留旧布局。没有重做标题栏或红黄绿。
- 点单位字体 pixelSize 为 -1 时保留原外观，不再向 Qt 传入 -5；显式像素字体的缩小结果保持为正值。

## 验证范围

新增隔离生命周期回归，使用真实生产调度／连接／取消／结果投递，覆盖一百个排队管理器删除、运行中删除、已排队结果晚到、存活页面正常回调、UI 线程投递和退出拒绝新任务。运行中测试只替换网络业务体为合成信号，不触及真实接口／令牌／账号。结果以候选旁验证记录为准，不把合成测试等同于真实评论服务验收。

继续精简 arm64、免费 ad-hoc 签名、未公证、自用候选。主 App 与剪藏器独立；本轮不构建、安装或测试剪藏器上传。多机安装、异常磁盘保存失败、全部网页引擎析构卡顿、完整第三方素材和 Qt 对应源码公开发行审计仍有待验收项。
